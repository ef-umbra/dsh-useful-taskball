# dsh-useful-taskball

在 DeepSeek Harness 里常驻一个**可拖动的任务状态悬浮球**，用扇形分色实时显示所有会话的任务状态。不用逐个切换会话，看一眼球就知道哪里出了问题、哪里在等你。

## 它做什么

**一眼看全局**：球按颜色等分，一个正在处理中的会话占一个扇形。会话增减时扇区边界会**平滑滑动**——一个扇区消失时被邻居吞并，新扇区出现时从邻居那里冒出来。超过 8 个扇区时改为直接切换（仍然每个都显示，只是没有过渡）。

| 颜色 | 含义 |
|---|---|
| 🔴 红 | 任务中断或失败 |
| 🟡 黄 | 有任务等你审批或决策 |
| 🔵 蓝 | 有任务正在执行 |
| 🟢 绿 | 任务已完成 |
| ⚪ 灰 | 暂无任何状态 |

同时命中多个状态时取最高优先级：**红 > 黄 > 蓝 > 绿**。灰色不占扇形，无任务时球整体呈灰。

**点开就是一个任务面板**：按工作区分组列出所有需要你处理的会话，点标题直接跳过去。球和面板永远是同一份数据 —— 面板里在「未处理」区，球上就有它的扇形；勾了「已处理」，两处一起消失。

**状态一变就提醒你**：任务从执行中转成失败或等你审批时，球旁边弹一个气泡，颜色跟着新状态走、尖角指着球。点一下能跳过去，几秒后自动收起（时长可调）。任务完成是否也提醒，由你决定。

**完成的任务自动收纳**：已完成会话在面板底部「已处理」区待着，可展开可撤销，超过设定的保留时长就自动消失。失败、待审批、执行中的会话**永不自动消失** —— 需要你动手处理。

**三种方式让红色退场**：勾选「已处理」（失败项会先问你一次）、归档会话、或者重新在那个会话里发消息。

**写了一半没发出去的会话，也能看见**：面板最上方有一个「草稿」区，把还有未发送内容的会话列出来，点一下就能跳回去接着写。它不按工作区分组（草稿不属于任何工作区），没有标题的新会话显示为「新会话」。**每行左侧的图标说明它是哪一种**：文件夹 = 工作区里还没写过的新会话，气泡 = 已经聊过、只是还留着半句话的老会话。草稿不是任务状态，所以**球上不会有任何变化**。没有草稿时这一区不出现。

**嫌它占地方就收起来**：右键球 →「收起成竖条」，球变成一条细竖条贴在消息输入框左边。竖条从上到下按任务状态分色，**一个任务一段**：有几个未处理任务就分几段，颜色就是那个任务的状态色，顺序固定为 失败 → 待处理 → 执行中 → 已完成。**四周有一圈 1px 白边**（外面还有一道极淡的贴边，所以浅色主题的白底上也看得见），宽度仍是 13px 没变粗。点一下竖条就变回原来的球，位置还是收起前那个位置。没有任务时竖条显示一段中性灰，不会整条消失；任务多到每段不足 4px 时会自动省掉段间细线。窗口太窄、输入框左边放不下时，它会**自动保持球的形态**，不会挤到侧栏上去。收起状态会记住，刷新后仍是竖条。

## 安装

```bash
npm install
npm run build
```

装进 DSH：`dsh plugin add link:<仓库路径>`。

## 怎么用

- **拖动**球到顺手的位置，位置会被记住。拖到**侧栏分界线**或**屏幕四边**附近松手，球会自己贴上去；之后侧栏展开收起、右栏开关、窗口缩放，贴着的球会跟着那条线走。松手时离多近才吸附由设置里的「吸附距离」决定，**设成 0 就是完全不吸附**。
- **点击**球展开任务面板，再点一次收起（球会反向转一下）。
- **右键**球打开**快捷设置**（磨砂小面板）：**球大小**、磨砂、面板不透明度、**完成时是否弹提醒**、**是否显示已处理区**、**面板字号**，改完立刻生效；底部并排两个出口 —— 一步跳到全部设置，或者在这里把球**收起成竖条**。键盘用 `Shift+F10`，或点任务面板首行的齿轮。放这里的判据是「**看着球才想起来要改的**」，所以「状态表示」「色盲友好配色」这类设一次就不再动的不在这儿，去完整设置页。
- 面板每行右侧的勾选框就是「已处理」；勾了会移到下方折叠区，随时可以撤销。**失败**条目的勾选会先弹出一个确认条：整行向左滑走，原位出现「取消 / 确认已处理」两块，点「确认」才真正折叠（也可以按 Esc 取消）。
- **按住 `Shift` 再勾选任意一条失败**，会弹出一个窗口列出**当前所有**待处理的失败会话标题，底部「取消 / 全部确认」两块。确认后这些失败条目一起移入已处理区——批量处理失败，但每一条都看得见。
- **按住 `Shift` 再勾选任意一条已完成**，会直接把**当前所有**已完成条目一起移入已处理区，不用再确认。已完成的东西本来就会自己过期，藏起来也没有代价。

## 设置

入口在 DSH「插件 → 已安装插件 → Taskball · 任务状态悬浮球」（或快捷面板里的「打开全部设置」），分成三个标签：

**外观**

- 已处理区显示开关、是否显示已处理计数
- **悬浮球大小**：三档可选 —— 小 36 px / 中 44 px（默认）/ 大 56 px。**只改球本身**，任务面板和提醒气泡尺寸不变，只是重新对齐到新的球上；球变大后扇形之间的细缝视觉粗细保持不变。
- **面板的质感**：不透明度用**滑块**调（30–100%，右侧实时显示百分比）与**磨砂玻璃**开关。**默认是磨砂 + 30% 不透明度** —— 面板半透明、背后的内容被模糊掉，因为透得足够多，**应用的底色会透上来**，换主题或装皮肤时面板也跟着变色调。想要原来那种实心面板，把不透明度拉回 100，或者把磨砂关掉。
- **色盲友好配色**（默认关）：把「失败」和「完成」的红绿换成紫红与青绿。红绿色盲约占男性 8%，默认的红绿在他们眼里几乎是同一个颜色，而这两色恰好代表最需要区分的「出问题了」和「搞定了」。打开后黄色、蓝色、灰色不变。
- 面板里每行如何表达状态色：色条 / 圆点 / 整行实色 / 整行浅染 / **整行浅染 + 细描边**（浅色主题黑线、深色主题白线）/ 整行实色 + 空白方块；行与行之间留一道极细的缝
- 面板字号（跟随应用 / 自定义 px）

**动效**

- 勾选时的动效（向外淡出 / 向下移入）；条目移出时面板高度会跟着平滑收缩，不会突然跳一下
- **吸附距离**（0–48 px，默认 16）：松手时离分界线或屏幕边缘多近，球才会吸过去。**设成 0 就是完全不吸附**，球落在哪就是哪，已经吸住的球也会立刻松开。
- 气泡显示时长
- 点击面板外是否关闭面板（默认开）

**通知**

- 完成态保留时长（分钟）
- 完成时是否弹提醒
