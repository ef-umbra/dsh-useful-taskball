# Taskball · 任务状态悬浮球

给 DeepSeek Harness 加一个悬浮球，**用颜色告诉你哪个会话出问题了、哪个在等你、哪个还在跑**。

不用再一个个点开会话看进度 —— 看一眼球就知道了。

## 五种颜色

| 颜色 | 含义 |
|---|---|
| 🔴 红 | 任务中断或失败 |
| 🟡 黄 | 有任务等你审批或决策 |
| 🔵 蓝 | 有任务正在执行 |
| 🟢 绿 | 任务已完成 |
| ⚪ 灰 | 暂无任何状态 |

球的颜色按会话数等分：几个会话有状态，就分成几个扇形，每个扇形是那个会话的颜色。同时命中多个状态时取最高的 —— **红 > 黄 > 蓝 > 绿**。没有任务时球是灰的。

## 能做什么

**一眼看全局** — 球上每个扇形对应一个会话，颜色就是它的状态。会话增减时扇形会平滑地滑开或收拢。

**点开就是任务面板** — 按工作区分组列出所有要处理的会话，点标题直接跳过去。球和面板永远一致：面板里勾了「已处理」，球上对应的扇形也一起消失。

**状态一变就提醒** — 从「执行中」转成失败或等你审批时，球旁边弹一个气泡，点一下能跳过去。任务完成要不要也提醒，由你决定。

**完成的任务自动收纳** — 已完成的会话收进面板底部，可以展开、可以撤销，过了保留时长就自动消失。失败、待审批、执行中的**永远不会自己消失**，必须你处理。

**草稿也能看见** — 写了半句还没发出去的会话，列在面板最上方，点一下回去接着写。每行左侧有图标区分：文件夹 = 还没写过内容的新会话，气泡 = 聊过、还留着半句话的老会话。

**嫌占地方就收起来** — 右键球选择收起，球会变成一条细竖条贴在输入框左边。竖条按任务状态分段着色，一个任务一段。点一下就变回球，位置还是收起前那个位置。

## 安装

```bash
dsh plugin add github:ef-umbra/dsh-useful-taskball
```

要求 DeepSeek Harness `0.2.1-rc.3` 或更高。

## 怎么用

**球本身**

- **拖动**到顺手的位置，位置会记住。拖到侧栏分界线或屏幕边缘附近松手，球会自己贴上去；之后侧栏展开、右栏开关、窗口缩放，贴着的球会跟着移动。
- **点击**展开任务面板，再点一次收起。
- **右键**打开快捷设置，常用的几项在这儿：球大小、磨砂、面板不透明度、状态突变提醒、是否显示已处理区、面板字号。底部还能一步跳到完整设置，或者把球收起来。键盘用 `Shift+F10`，也可以点面板首行的齿轮。

**处理任务**

- 面板每行右侧的勾选框就是「已处理」。勾上会移到下方折叠区，随时可以撤销。
- **失败**的条目光勾选会先问你一次：整行滑走，原位出现「取消 / 确认已处理」两块，点确认才真的折叠。也可以按 `Esc` 取消。
- **按住 `Shift` 再勾选失败**，会列出当前所有待处理的失败会话，一次确认全部处理 —— 批量操作，但每一条都看得见。
- **按住 `Shift` 再勾选已完成**，直接把所有已完成的一起收纳，不用确认。

**让红色退场**，三种方式任选：勾选「已处理」、归档那个会话、或者回去在会话里发条消息。

## 设置

入口在 DSH 的「插件 → 已安装插件 → Taskball · 任务状态悬浮球」，也可以在快捷面板里点「打开全部设置」。分三个标签：

**外观**

- 悬浮球大小：小 / 中 / 大
- 面板质感：不透明度滑块 + 磨砂玻璃开关。默认是半透明磨砂，会透出应用底色，换主题或装皮肤时面板也跟着变。
- 色盲友好配色：把「失败」和「完成」的红绿换成紫红和青绿。红绿色盲约占男性 8%，而这两色恰好代表最需要分清的「出问题了」和「搞定了」。
- 状态表示：矩形 或 圆点，选面板里每行怎么显示状态色。
- 面板字号、是否显示已处理区、是否显示已处理计数

**动效**

- 勾选时的动画（向外淡出 / 向下移入）
- 吸附距离：松手时离边缘多近才吸附。设成 0 就是完全不吸附。
- 气泡显示时长、点击面板外是否关闭

**通知**

- 状态突变提醒（默认开）：关掉之后任何气泡都不弹，包括失败提醒。
- 完成态保留时长：已完成会话在面板里留多久。
